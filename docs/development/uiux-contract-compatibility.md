## Adapter boundary

`apps/admin-portal/src/features/contracts/lifecycle.ts` is a pure presentation adapter over already validated API results. It introduces no requests, cache, server state, policy evaluation or wire DTO. It preserves draft metadata and revision, maps every existing upload state, and records exact discovered immutable version identity. Latest version, processing, approval and publication remain unknown where their evidence is absent. Future missing workflow availability is explicitly unavailable; this does not deny or authorize existing backend operations. These view models must never be sent as command DTOs.

A session/tenant boundary must discard Query-derived presentation values along with protected cache entries. Cancellation without cache removal is insufficient; adapters do not replace that boundary. All strings remain untrusted text for React rendering, never HTML.
