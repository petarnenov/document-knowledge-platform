Its constructor checks size1..1048576, SHA256 consistency and identity/digest shape; the inbound validation adapter binds those fields to the full strict versioned JSON schema. No JDBC/JSON/filesystem/framework dependency points inward.

Outbound `JdbcLogManifests` uses the existing logging-owned `dev_logs.manifests`/`capacity` tables without changing V1. Install takes the same first capacity row lock used by event/cleanup writers. Any SQL failure/expiry rolls back; a failed/late commit response makes no installed claim. Pass the original RequestDeadline through positive statement/network limits and existing bounded JdbcLogCleanup; no new background executors or retry loops. An operator connection has registration/migration authority; query-only role cannot install. No runtime automatically upgrades the running read-only service or writes synthetic manifests there.

## Private operator adapter

Use the bootstrap layer's already pinned Jackson3 parser, strict duplicate detection, trailing-token rejection, malformed UTF-8 rejection, depth16, document1MiB, bounded strings/numbers and complete closed-key/type/range validation of `contracts/v1/build-manifest.schema.json`. Validate nonnil lower-case UUID, exact build/source/toolchain/dependency/vocabulary digests, RFC3339 timestamp, literal version1 and sourceFingerprintAlgorithm, dirty boolean, unique bounded event/phase/error/class/frame catalogs, dependency records and source-relative frames. Require all16 versioned EventCode names; additional syntactically valid event codes may exist only in the operator-reviewed manifest. No exception/catalog symbols are learned from event data. Duplicate dependency names are rejected to keep lookup unambiguous.

Verify caller expectedSHA against EXACT file bytes before parsing. The operator file is owner-only regular with no symlink and bounded1MiB. Check inode/owner/mode/size/modification before+after a NOFOLLOW read. A caller supplies no URL or filename-derived authority. The canonical-byte check rejects whitespace/key-order/escape differences instead of silently relabeling a different manifest digest. For this schema the only number is schemaVersion=1, so canonicalization handles only strings, booleans, integer1, arrays and sorted-key objects; no general floating-point canonicalizer is introduced. Follow RFC8785 UTF-16 key ordering, lowercase control escapes, untouched Unicode and rejection of lone surrogates. Compute vocabularySha256 over that same canonical vocabulary encoding. Retain only original raw bytes in SQL, not a second filesystem registry. The operator is responsible for selecting reviewed catalog content; shape/hash validation is not proof of compiler provenance or code authenticity.

The private adapter is an internal callable bootstrap boundary in this slice. Its subsequent CLI/producer registration wiring remains explicitly open; no manifest upload endpoint, complete registry authentication, disk observer or ingestion claim. Do not expose the installation API through the read-only running assembly.
