## Bounded local record port and external forwarding

Version a closed inspector-log-record schema under contracts/schemas/v1 before implementing its parser. Each UTF8 LF-delimited stdout record has fixed prefix DKP-INSPECTOR-LOG/1 and schemaVersion1, original buildId, runId, instanceId, manifestSha256, a typed event and monotonically cumulative bounded loss counters. Event retains its worker-created UUID/timestamp/correlation/trace, closed common eventName/severity/phase/outcome/duration/attempt/count/cleanup facts and optional typed diagnostics; no free text/maps. Maximum complete record8192 bytes, event6144 bytes, queue128 records and1MiB. Exception material is sanitized before retention/output against the embedded original catalog, and revalidated externally. Queue admission is nonblocking; only one daemon writer touches stdout. A blocked/broken output cannot block inspection or change HTTP results. Loss/invalid/closed/writer-failure counts are queryable from the adapter and included in subsequent emitted status; if the stream stalls or exits the external status reports unknown/degraded, never COMMITTED. No worker-side secret/spool/socket/network transport. Normal shutdown is bounded and does not assert durable flushing.

The external trusted runtime starts/owns one bounded forwarder for the exact owned worker container/process, actual immutable image and original manifest, with fixed arguments and producer-only finite registration, strict TLS, existing scoped receipts and private bounded spool. It reads only that worker stream, never arbitrary caller-selected container/path/command; no Docker authority is mounted into the worker. Bound each line before parsing, reject duplicate/unknown fields, oversized/malformed/unregistered/mismatched identities and invalid enum/count/frame/source values without retaining raw input. Drain oversized lines with bounded memory. Preserve original eventId/timestamp and worker identity through replay; deduplicate with existing event receipt semantics, never regenerate the identity as a Python compilation. Process/run replacement requires a new explicitly bound configuration, not guessed continuation. Bound Docker log rotation/readback as well as SDK memory/disk; expose input rejection/loss/stall/EOF, SDK pending/unknown/rejected/dropped and last delivery state in a private status file without raw records/secrets. A forwarder failure is visible and does not stop/restart the parser.

Use the existing Python SDK asynchronous durable producer/HTTPS/scoped receipts, extending its closed typed optional diagnostics codec/catalog and spool restore validation to the existing common v1 diagnostic fields. This fills a reusable SDK capability, not a second transport or arbitrary payload bypass. Preserve lifecycle-only callers and their existing wire bytes. Full diagnostic events, replay and ordinary outage/restart recovery must be tested; producer enqueue is not proof of persistence. Producer credentials and registrar authority stay outside the worker, with no collector lifecycle coupling. Logging all other tools/infra/CI remains rank4.
